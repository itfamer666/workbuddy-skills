# 提问清单与沟通策略写法

## 一、为什么清单是报告里最实用的一页

如果把整份报告比作弹药，破冰提问清单就是**开第一枪**。
它的作用是把对话从"AI 能做什么"切换到"**您的业务卡在哪里**"。

> 对方每回答一个问题，就等于为你免费做了一次需求调研。

因此清单要有**可勾选 + 本地保存**的交互（模板已内置，localStorage 持久化，带进度条）。

---

## 二、通用提问模板（12 题，按场景挑 8~12 条）

### 战略层（问董事长 / 总经理）
1. 今年提出的 `<核心战略方向>`，落地时主要靠什么数据和流程做决策？现在这套流程最卡的地方在哪？
2. 如果只能选一个场景做 AI 试点，您希望是哪一个？判断标准是什么？
3. 下一个三年，您最担心的三件事是什么？

### 获客与转化层（问市场 / 销售负责人）
4. 现在的线索来源结构大概是怎样的（投流 / 垂直平台 / 直播 / 自然到店）？从线索到成交的漏斗，**哪一环流失最严重**？
5. 非工作时间（夜间、节假日）来的线索，现在怎么处理？
6. 私域（企微 / 社群 / 公众号）现在有多少人运营？内容主要由谁生产？一线同事反映最大的困难是什么？

### 服务与留存层（问售后 / 客服负责人）
7. 客服日均接多少通？SLA 达成率如何？高峰期和夜间怎么扛？
8. 客户基盘里活跃客户占比多少？流失客户的召回现在是人工做还是系统做？
9. 一个新员工从入职到能独立产出，平均培养周期多长？主要卡在哪？

### 系统层（问 IT / 数据负责人）★ 否决点
10. 各业务系统之间数据是打通的还是各自独立？管理层要一个跨板块的经营数据，现在要多久拿到？
11. IT 团队规模和职责？自研还是外采？**对 AI 类系统的部署方式（公有云 / 私有化）有没有既定要求？**
12. 数据能不能出企业？有没有等保、分级分类、审计方面的硬性要求？

> **第 11、12 题通常决定这一单能不能成。** 一定问，且要提前单独沟通，不要留到大会上问。

## 三、沟通策略的写法（第 11 章）

### 1. 分角色话术（第 3 章的每条人物都要有）

三段式：
```
【他是谁】职务、决策角色、公开主张
【建议话术】直接引用他讲过的原话 + 你的回应句式
【避免/注意】哪类表述会让他反感
```

示例：
> **建议话术**："您提的『横向扩园区、纵向调品牌』，我们拆成可落地的三步……"
> **避免**：风口、颠覆、替代人、短期 ROI 承诺。

### 2. 三个必做动作（几乎通用）
1. **引用他们自己的话** —— 方案每页尽量挂一句对方公开提出的关键词
2. **先算账，再谈技术** —— 必有投入产出测算表，而不是功能清单
3. **主动提合规与部署方式** —— 主动说数据边界会显著加分

### 3. 切入路径（样板间打法）
```
选 1 个业务单元（总部 / 旗舰单元）+ 1 个场景
→ 4~6 周做出可量化效果
→ 借对方已有的动员机制（年会 / 例会 / 复盘会）横向复制
```
**关键：顺着这家公司的组织复制基因去打。** 如果它当年就是靠"园区复制"扩张的，就用园区复制的方式推 AI。

## 四、识别三类关键人

| 角色 | 怎么识别 | 怎么对待 |
|---|---|---|
| **拍板人** | 公开曝光最多、头衔含"董事长/总裁/投资人"， external 讲话做战略定调 | 引用其原话，给投入产出表 |
| **业务对口人** | 总监/条线负责人，年度会议里做业务复盘的那批人 | 第一场业务会就约，带具体 Demo |
| **否决点** | IT / 信息中心 / 风控负责人，多不对外曝光 | **必须提前单独沟通**，定位为"赋能 IT 而非替代 IT"，提供私有化 + 可二次开发 + 接口开放 |

> 拍板人决定"要不要做"，业务对口人决定"做什么"，否决点决定"能不能买"。三者缺一不可。
