# examples/

本目录用于存放**填好数据的成品报告范例** —— 写新报告前先看一眼成品，能显著提升信息密度。

## 为什么这里是空的

仓库里的成品范例来自真实客户调研（含管理层姓名、沟通策略、内部定价逻辑），
属于客户敏感信息，因此**不随公开仓库分发**。

本地 `~/.workbuddy/skills/company-research-report/examples/` 中保留完整范例，
`SKILL.md` 里对范例的引用在本地安装下正常工作。

## 想看范例怎么办

把任一交付过的报告 HTML 放进本目录即可，例如：

```bash
cp <某次交付的研究报告>.html \
   ~/.workbuddy/skills/company-research-report/examples/
```

建议至少保留一份，它回答的问题是「什么叫做把数据写透了」。
