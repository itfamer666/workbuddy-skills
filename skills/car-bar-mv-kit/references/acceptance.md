# 验收清单与报告模板

原则：**读回产物，不凭提示词推断**。按 `quality-gates` 要求，逐件过、整批过，无从确认的项如实标注。

---

## 一、静态图（每张）

### 逐件核对（图像查看能力）

1. 场景是否为指定风格；有无串入其他风格元素（如西式工业梁混进东方夜店）。
2. 前景主唱性别、中国面孔、手持麦克风演唱姿态、黑色舞台装是否到位。
3. 车上主要特征是否与车型特征卡一致；车身是否与暖金夜景灯光融合，无白天平光、白边、贴片矩形边界、柏油地面或原照片背景。
4. 车是否落在圆形展台上，接触阴影与地面倒影自然、透视一致，四轮完整、无遮挡。
5. 旧中性概念车是否有残留（溜背弧线、旧车轮、板件）。
6. 车后四位乐手人数、位置、乐器、中国面孔是否正确。
7. 画面内有无额外文字、汉字、LOGO、字幕。
8. 右下角角标是否清除、修补处有无可见痕迹。

### 量化检查

```bash
python3 -c "from PIL import Image; im=Image.open('<图>'); print(im.size)"
```
- 两张必须同为 `2048×1152`。
- 角标区亮度 >42 的近中性像素数应为 0；另生成 2× 放大拼接图目视复查无接缝。

### 成套检查

两张的车形态 / 角度 / 位置 / 灯光 / 倒影、场景 / 棂格 / 月洞门 / 乐队 / 调性一致，**差异仅为主唱**。

## 二、视频（每条）

```bash
python3 scripts/verify_video.py <视频.mp4> --out-dir <验收目录>
```

脚本输出：元信息摘要、音轨音量、5 帧拼图、末帧右下角放大图。依次核对：

| 项 | 判据 |
|---|---|
| 产物有效性 | 返回状态 completed，本地 MP4 路径存在且非空 |
| 时长 | 实读约 5.17 秒（按文件实值汇报，不复述 `duration=5`） |
| 画幅 / 帧率 | 2560×1440（2K / 16:9）/ 24fps / 约 124 帧 |
| 音轨 | `volumedetect` 读数；确认是服务侧附带音轨，交付须提示后期静音或替换 |
| 主唱 | 各帧嘴部 / 头部 / 手势有自然变化，脸部身份稳定无漂移 |
| 车辆 | 全程原地不动，形态 / 角度 / 比例 / 格栅 / 轮毂 / 车标 / 牌照框稳定；仅高光、车灯、倒影变化 |
| 乐队 | 四位乐手有演奏动作，人数与位置不变 |
| 场景 | 风格要素一致，单一缓推，无跳切、无镜头剧变 |
| 画面洁净 | 无新增文字 / 汉字 / LOGO / 字幕；右下角无角标水印 |
| 画布 | 本批所有成片在同一张 `.miora` 画布上 |

### 跨片段对比（两条都生成时做）

取同一时间点（建议 `t=2.5s`）的车区域并排放大，核对车型、角度、占比、高光与伪文字。若存在可见差异（**预期会有**），在交付说明中写明「不可同镜头硬接」并给出转场建议。

### 明确标注为「无法确认」

- 画面是否流畅、运镜是否连贯
- 口型与音乐是否贴合（本就是自然演唱动作，未与音乐对齐）

这三项只能由用户实际播放判断，不得断言合格。

## 三、交付报告模板

```
【规格】静态图 2 张 2048×1152；视频 2 条 5.17 秒 / 2560×1440 / 24fps
（分辨率说明：1080p 不被支持，改用接口允许的 2K）

【逐件验收】
- 主唱 / 中国面孔 / 演唱动作：…
- 车辆形态与静止状态、光影流动：…
- 乐队、场景、灯光：…
- 角标 / 新增文字：…
- 音轨（实测 mean/max dB）：…

【成套验收】两图差异仅主唱；两段视频存在可见车辆漂移，不可硬接

【必须提示】
1. 成片自带服务侧音轨，后期需静音或替换
2. 口型为自然演唱动作，未与指定音乐逐字对齐
3. 配乐、精对、成片合成在剪辑环节完成
4. 中文牌照小字不可精确还原（若适用）

【无法确认】流畅度 / 运镜连贯性 / 口型贴合度，需自行播放查看

【产出】新建画布、图片目录、视频目录、技能调用记录（含算力口径）
```

## 四、常见失败与处置

| 现象 | 原因 | 处置 |
|---|---|---|
| 视频提交 400 / `unsupported video resolution` | 传了 `1080p` | 改 `2K`，一次修正，不反复试探 |
| 图右下角仍有小字残留 | 修补区四周都做了羽化 | 右/下边界全强度替换，扩大保守区重做 |
| 车身像贴上去的、有硬边界 | 用了抠图合成 | 改双图参考原生重绘，重出该张 |
| 两张图的车不一致 | 并行独立生成或派生时又传了车图 | 回到锚点链串行派生，只传成品图 |
| 男歌手变成混血脸 | 面部描述没写全 | 补齐东亚骨相 + 四项排除短语 |
| 超时未拿回视频结果 | 视频生成较慢 | 先查后端任务状态，不要当成失败重发，避免重复计费 |
